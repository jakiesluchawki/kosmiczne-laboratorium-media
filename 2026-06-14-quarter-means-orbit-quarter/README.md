# Kwadra to ćwiartka drogi, nie tarczy

Gotowy pakiet wyjaśniający pozorny paradoks pierwszej i ostatniej kwadry.
Nazwa mówi o położeniu Księżyca na jego miesięcznej drodze, natomiast z Ziemi
widzimy wtedy około połowy oświetlonej tarczy.

- `instagram-stories/` - pięć plansz 1080 x 1920;
- `facebook-linkedin/` - dwa obrazy 1200 x 1500;
- `quarter-means-orbit-quarter.zip` - pełna paczka do publikacji;
- `linkedin-facebook-post.md` - osobne teksty dla obu kanałów;
- `preview.png` - podgląd całego zestawu;
- `manifest.json` - pochodzenie grafiki i źródła.
