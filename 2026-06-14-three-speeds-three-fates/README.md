# Trzy prędkości, trzy zupełnie różne losy

Gotowy pakiet o tym, że większa prędkość nie oznacza automatycznie lepszej
orbity. W tym samym modelu za wolny rzut kończy się upadkiem, prędkość „w sam
raz” daje zamkniętą orbitę, a zbyt szybki rzut może prowadzić do ucieczki.

- `instagram-stories/` - pięć plansz 1080 x 1920;
- `facebook-linkedin/` - dwa obrazy 1200 x 1500;
- `three-speeds-three-fates.zip` - pełna paczka do publikacji;
- `linkedin-facebook-post.md` - osobne teksty dla obu kanałów;
- `preview.png` - podgląd całego zestawu;
- `manifest.json` - pochodzenie grafiki i źródła.
