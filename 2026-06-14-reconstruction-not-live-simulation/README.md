# Rekonstrukcja nie udaje symulacji na żywo

Gotowy pakiet o uczciwym opisie modeli. Kosmiczny plac zabaw oblicza ruch na
żywo, natomiast historie Apollo 13, Voyagera 2 i Galileo są etapowymi
rekonstrukcjami prawdziwych misji. Aplikacja mówi o tej różnicy wprost.

- `instagram-stories/` - pięć plansz 1080 x 1920;
- `facebook-linkedin/` - dwa obrazy 1200 x 1500;
- `reconstruction-not-live-simulation.zip` - pełna paczka do publikacji;
- `linkedin-facebook-post.md` - osobne teksty dla obu kanałów;
- `preview.png` - podgląd całego zestawu;
- `manifest.json` - pochodzenie grafiki i źródła.
