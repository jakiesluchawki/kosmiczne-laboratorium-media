# Supermasa nie rośnie, tylko mocniej trzyma

Gotowy pakiet o realnej funkcji działającej aplikacji: `Superciężkiej`
Ziemi w odkryciu o masie i bonusowym wyzwaniu `Ucieczka od supermasy` w
`Kosmicznym placu zabaw`. Materiał pokazuje, że ilustracja planety może
zostać tej samej wielkości, a mimo to większa masa mocniej zakrzywia ruch i
utrudnia ucieczkę.

- `instagram-stories/` - pięć plansz 1080 x 1920;
- `facebook-linkedin/` - dwa obrazy 1200 x 1500;
- `supermass-harder-escape.zip` - pełna paczka do publikacji;
- `linkedin-facebook-post.md` - osobne teksty dla obu kanałów;
- `preview.png` - podgląd całego zestawu;
- `manifest.json` - pochodzenie grafiki i źródła.
