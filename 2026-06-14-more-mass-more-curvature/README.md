# Większa masa mocniej zmienia ruch

Gotowy pakiet o tym, co naprawdę zmienia się po zwiększeniu masy planety.
Grafika Ziemi pozostaje tej samej wielkości, ale w tej samej odległości
grawitacja mocniej przyspiesza piłkę, wyraźniej zakrzywia jej tor i podnosi
prędkość potrzebną do ucieczki.

- `instagram-stories/` - pięć plansz 1080 x 1920;
- `facebook-linkedin/` - dwa obrazy 1200 x 1500;
- `more-mass-more-curvature.zip` - pełna paczka do publikacji;
- `linkedin-facebook-post.md` - osobne teksty dla obu kanałów;
- `preview.png` - podgląd całego zestawu;
- `manifest.json` - pochodzenie grafiki i źródła.
