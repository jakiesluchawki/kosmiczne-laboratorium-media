# W tym wyścigu nie ma kierownicy

Gotowy pakiet o zręcznościowym modelu orbity. Każdy pilot ma tylko hamulec
i dopalacz. Za blisko planety trzeba dopalić, za daleko zahamować, a pełne
okrążenie liczy się dopiero po przejechaniu większości obiegu po zielonym torze.

- `instagram-stories/` - pięć plansz 1080 x 1920;
- `facebook-linkedin/` - dwa obrazy 1200 x 1500;
- `orbit-race-no-steering-wheel.zip` - pełna paczka do publikacji;
- `linkedin-facebook-post.md` - osobne teksty dla obu kanałów;
- `preview.png` - podgląd całego zestawu;
- `manifest.json` - pochodzenie grafiki i źródła produktowe.
