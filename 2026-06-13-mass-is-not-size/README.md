# Cięższa planeta nie musi być większa

Gotowy pakiet o rozdzieleniu masy i rozmiaru. Dwa prawdziwe stany aplikacji
pokazują lekką Ziemię 1/3 i superciężką Ziemię 3/3 przy niezmienionym rozmiarze
planety. To celowy model porównawczy, który izoluje jedną zmienną.

- `instagram-stories/` - pięć plansz 1080 x 1920;
- `facebook-linkedin/` - dwa obrazy 1200 x 1500;
- `mass-is-not-size.zip` - pełna paczka do publikacji;
- `linkedin-facebook-post.md` - osobne teksty dla obu kanałów;
- `preview.png` - podgląd całego zestawu;
- `manifest.json` - pochodzenie grafiki i źródła produktowe.
