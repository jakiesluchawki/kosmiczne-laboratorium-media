# Każda widoczna masa zmienia tor

Gotowy pakiet o kosmicznym placu zabaw. Gdy na ekranie są dwie planety,
samochodzik nie wybiera jednej z nich. W każdym kroku model dodaje wpływ
wszystkich widocznych mas i z tej sumy wyznacza dalszy ruch.

- `instagram-stories/` - pięć plansz 1080 x 1920;
- `facebook-linkedin/` - dwa obrazy 1200 x 1500;
- `every-visible-mass-pulls.zip` - pełna paczka do publikacji;
- `linkedin-facebook-post.md` - osobne teksty dla obu kanałów;
- `preview.png` - podgląd całego zestawu;
- `manifest.json` - pochodzenie grafiki i źródła.
