# Jeden ekran, cztery układy grawitacji

Gotowy pakiet o realnej funkcji działającej aplikacji: bonusowym
`Kosmicznym placu zabaw`, w którym dziecko może przełączyć na jednym ekranie
`Pustą siatkę`, `Jedną planetę`, `Dwie planety` i `Supermasę`. Materiał
pokazuje, że nie są to osobne mini-gry, tylko cztery warianty tej samej
rozmowy o grawitacji i torze ruchu.

- `instagram-stories/` - pięć plansz 1080 x 1920;
- `facebook-linkedin/` - dwa obrazy 1200 x 1500;
- `one-screen-four-gravity-setups.zip` - pełna paczka do publikacji;
- `linkedin-facebook-post.md` - osobne teksty dla obu kanałów;
- `preview.png` - podgląd całego zestawu;
- `manifest.json` - pochodzenie grafiki i źródła.
