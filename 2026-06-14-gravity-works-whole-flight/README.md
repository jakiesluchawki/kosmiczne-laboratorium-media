# Grawitacja działa przez cały lot

Gotowy pakiet o tym, że grawitacja nie czeka do zderzenia. W każdym kolejnym
momencie lotu zmienia prędkość piłki w stronę Ziemi. Ruch w bok i przyspieszenie
ku planecie składają się w zakrzywiony tor.

- `instagram-stories/` - pięć plansz 1080 x 1920;
- `facebook-linkedin/` - dwa obrazy 1200 x 1500;
- `gravity-works-whole-flight.zip` - pełna paczka do publikacji;
- `linkedin-facebook-post.md` - osobne teksty dla obu kanałów;
- `preview.png` - podgląd całego zestawu;
- `manifest.json` - pochodzenie grafiki i źródła.
