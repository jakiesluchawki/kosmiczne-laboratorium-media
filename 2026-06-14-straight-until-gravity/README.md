# Tor nie zakręca sam

Gotowy pakiet o pierwszej zasadzie dynamiki pokazanej na dwóch ekranach tego
samego eksperymentu. Bez masy samochodziki poruszają się po prostych. Po
dodaniu planety grawitacja zmienia kierunek ich ruchu.

- `instagram-stories/` - pięć plansz 1080 x 1920;
- `facebook-linkedin/` - dwa obrazy 1200 x 1500;
- `straight-until-gravity.zip` - pełna paczka do publikacji;
- `linkedin-facebook-post.md` - osobne teksty dla obu kanałów;
- `preview.png` - podgląd całego zestawu;
- `manifest.json` - pochodzenie grafiki i źródła.

## Status

`ready`

## Ważne

Model celowo pomija tarcie. W codziennym świecie to głównie tarcie i opór
powietrza sprawiają, że poruszające się przedmioty zwalniają.
