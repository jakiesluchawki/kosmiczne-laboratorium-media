# Proca grawitacyjna krok po kroku

Gotowy pakiet o tym, że tryb `Czytaj i upraszczaj` nie wycina rekonstrukcji
misji Apollo 13. W Kosmicznym Laboratorium spokojniejszy odbiór zamienia ruch
w etapy z przyciskami `Poprzedni etap` i `Następny etap`, ale zostawia tę samą
sekwencję, wyjaśnienie i źródło NASA.

- `instagram-stories/` - pięć plansz 1080 x 1920;
- `facebook-linkedin/` - dwa obrazy 1200 x 1500;
- `gravity-assist-step-by-step.zip` - pełna paczka do publikacji;
- `linkedin-facebook-post.md` - osobne teksty dla obu kanałów;
- `preview.png` - podgląd całego zestawu;
- `manifest.json` - pochodzenie grafiki i źródła.
