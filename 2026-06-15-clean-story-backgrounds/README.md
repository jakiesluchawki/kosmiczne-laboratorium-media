# Czyste tła do Instagram Stories

Osiem gotowych teł 1080 x 1920 do samodzielnego uzupełnienia tekstem.

Pliki nie zawierają napisów, logo, ramek ani gotowego układu typograficznego.
Powstały z ilustracji używanych w Kosmicznym Laboratorium.

- `backgrounds/` - osiem osobnych plików PNG;
- `clean-story-backgrounds.zip` - wszystkie tła w jednym archiwum;
- `preview.png` - podgląd całego zestawu;
- `manifest.json` - wymiary i sumy kontrolne.
