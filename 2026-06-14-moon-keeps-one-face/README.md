# Księżyc obraca się i dlatego pokazuje prawie tę samą stronę

Gotowy pakiet o obrocie synchronicznym Księżyca. Jeden obrót wokół własnej osi
trwa tyle samo co jeden obieg Ziemi, dlatego z Ziemi widzimy prawie tę samą
półkulę. Materiał uczciwie zaznacza niewielką librację pomijaną w modelu.

- `instagram-stories/` - pięć plansz 1080 x 1920;
- `facebook-linkedin/` - dwa obrazy 1200 x 1500;
- `moon-keeps-one-face.zip` - pełna paczka do publikacji;
- `linkedin-facebook-post.md` - osobne teksty dla obu kanałów;
- `preview.png` - podgląd całego zestawu;
- `manifest.json` - pochodzenie grafiki i źródła naukowe.
