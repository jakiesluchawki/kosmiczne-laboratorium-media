# Nów nie gasi Księżyca

Gotowy pakiet o tym, że podczas nowiu Słońce nadal oświetla połowę Księżyca,
ale jasna połowa jest odwrócona od obserwatora na Ziemi. Kolejny ekran pokazuje
pojawienie się sierpa po przesunięciu Księżyca po orbicie.

- `instagram-stories/` - pięć plansz 1080 x 1920;
- `facebook-linkedin/` - dwa obrazy 1200 x 1500;
- `new-moon-still-lit.zip` - pełna paczka do publikacji;
- `linkedin-facebook-post.md` - osobne teksty dla obu kanałów;
- `preview.png` - podgląd całego zestawu;
- `manifest.json` - pochodzenie grafiki i źródła.

## Status

`ready`

## Ważne

Nów nie oznacza automatycznie zaćmienia Słońca. Orbita Księżyca jest nachylona
względem płaszczyzny orbity Ziemi, dlatego podczas większości nowiów cień
Księżyca mija Ziemię.
