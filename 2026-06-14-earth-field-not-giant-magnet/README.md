# Ziemia nie ma w środku wielkiego magnesu

Gotowy pakiet o ziemskim polu magnetycznym. Kompas reaguje na pole Ziemi,
ale planeta nie skrywa jednej wielkiej sztabki. Większość pola powstaje dzięki
ruchowi płynnego, przewodzącego żelaza w jądrze zewnętrznym.

- `instagram-stories/` - pięć plansz 1080 x 1920;
- `facebook-linkedin/` - dwa obrazy 1200 x 1500;
- `earth-field-not-giant-magnet.zip` - pełna paczka do publikacji;
- `linkedin-facebook-post.md` - osobne teksty dla obu kanałów;
- `preview.png` - podgląd całego zestawu;
- `manifest.json` - pochodzenie grafiki i źródła naukowe.
