# Prawdziwe głosy były planem

Pakiet premierowy Kosmicznego Laboratorium opowiada o świadomej decyzji
projektowej: syntetyczne głosy pomogły zbudować prototyp, ale finalna aplikacja
od początku miała mówić prawdziwymi głosami. Feedback sześciolatka tylko
utwierdził autora, że warto ten plan doprowadzić do końca.

- `instagram-stories/` - osiem plansz 1080 x 1920;
- `instagram-carousel/` - sześć plansz 1080 x 1350;
- `facebook-linkedin/` - osobne grafiki dla obu kanałów;
- `copy/` - gotowe treści na LinkedIn, Facebook i Instagram;
- `human-voices-were-the-plan.zip` - pełna paczka do publikacji;
- `preview.png` - podgląd całego zestawu;
- `stats-and-methodology.json` - statystyki oraz sposób ich liczenia;
- `manifest.json` - lista i sumy kontrolne eksportów.
