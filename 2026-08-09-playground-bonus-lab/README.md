# Kosmiczny plac zabaw obok sześciu odkryć

Gotowy pakiet o pierwszym nieużytym temacie, który jest naprawdę dostępny w
działającej aplikacji: bonusowej karcie `Kosmiczny plac zabaw` na mapie misji.
Materiał pokazuje, że obok sześciu głównych odkryć jest też osobna pracownia
do własnych prób bez punktów i bez kolejności, ale nadal z hipotezą,
zmienianiem masy i obserwacją prawdziwego toru.

- `instagram-stories/` - pięć plansz 1080 x 1920;
- `facebook-linkedin/` - dwa obrazy 1200 x 1500;
- `playground-bonus-lab.zip` - pełna paczka do publikacji;
- `linkedin-facebook-post.md` - osobne teksty dla obu kanałów;
- `preview.png` - podgląd całego zestawu;
- `manifest.json` - pochodzenie grafiki i źródła.
