# Wstęp można obejrzeć jeszcze raz z mapy misji

Gotowy pakiet o tym, że intro do Kosmicznego Laboratorium nie znika po
pierwszym uruchomieniu. Na ekranie głównym zostaje zwykły przycisk
`Obejrzyj wstęp`, więc dziecko albo dorosły mogą wrócić do pięciu krótkich
rozdziałów bez resetowania postępu.

- `instagram-stories/` - pięć plansz 1080 x 1920;
- `facebook-linkedin/` - dwa obrazy 1200 x 1500;
- `rewatch-intro-from-home.zip` - pełna paczka do publikacji;
- `linkedin-facebook-post.md` - osobne teksty dla obu kanałów;
- `preview.png` - podgląd całego zestawu;
- `manifest.json` - pochodzenie grafiki i źródła produktowe.
