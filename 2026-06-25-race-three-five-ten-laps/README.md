# Wyścig orbitalny: 3, 5 albo 10 zielonych okrążeń

Gotowy pakiet o działającym wyścigu orbitalnym dla dwojga, w którym długość
gry można ustawić na `3`, `5` albo `10` zielonych okrążeń bez zmieniania
samej reguły lotu. Krótsza seria pozwala spokojnie wejść w rytm hamowania i
dopalania, a dłuższa zamienia ten sam model w pełniejszy pojedynek.

- `instagram-stories/` - pięć plansz 1080 x 1920;
- `facebook-linkedin/` - dwa obrazy 1200 x 1500;
- `race-three-five-ten-laps.zip` - pełna paczka do publikacji;
- `linkedin-facebook-post.md` - osobne teksty dla obu kanałów;
- `preview.png` - podgląd całego zestawu;
- `manifest.json` - pochodzenie grafiki i źródła.
