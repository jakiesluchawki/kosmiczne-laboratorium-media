# Proca grawitacyjna nie jest kosmicznym odbiciem

Gotowy pakiet o tym, jak naprawdę działa asysta grawitacyjna. Sonda nie odbija
się od planety i nie musi jej dotykać. Grawitacja płynnie zakrzywia tor, a w
układzie związanym ze Słońcem może zmienić się także prędkość sondy.

- `instagram-stories/` - pięć plansz 1080 x 1920;
- `facebook-linkedin/` - dwa obrazy 1200 x 1500;
- `gravity-assist-not-a-bounce.zip` - pełna paczka do publikacji;
- `linkedin-facebook-post.md` - osobne teksty dla obu kanałów;
- `preview.png` - podgląd całego zestawu;
- `manifest.json` - pochodzenie grafiki i źródła.
