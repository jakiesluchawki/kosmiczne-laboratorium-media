# Galileo poleciał ku Wenus, żeby dotrzeć do Jowisza

Gotowy pakiet o trasie VEEGA. Ciężka sonda Galileo nie mogła polecieć
bezpośrednio do Jowisza z użytym stopniem rakietowym, dlatego najpierw
skierowała się ku Wenus, a potem dwa razy wróciła obok Ziemi.

- `instagram-stories/` - pięć plansz 1080 x 1920;
- `facebook-linkedin/` - dwa obrazy 1200 x 1500;

- `linkedin-facebook-post.md` - osobne teksty dla obu kanałów;
- `preview.png` - podgląd całego zestawu;
