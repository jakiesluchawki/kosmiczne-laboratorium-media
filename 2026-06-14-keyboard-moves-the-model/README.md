# Nie trzeba przeciągać planety

Gotowy pakiet o równoważnym sterowaniu kosmicznym placem zabaw. Planetę można
przeciągnąć, przesunąć dużymi przyciskami albo obsłużyć klawiaturą. Każda
droga zmienia ten sam model.

- `instagram-stories/` - pięć plansz 1080 x 1920;
- `facebook-linkedin/` - dwa obrazy 1200 x 1500;
- `keyboard-moves-the-model.zip` - pełna paczka do publikacji;
- `linkedin-facebook-post.md` - osobne teksty dla obu kanałów;
- `preview.png` - podgląd całego zestawu;
- `manifest.json` - pochodzenie grafiki i źródła.
